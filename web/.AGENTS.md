# Directory: web/

## Purpose
Интерфейсы (C-04): два приложения React 19 + TypeScript и два пакета в одном npm-workspace.
Проверки: `eslint` (плоская конфигурация), `tsc -b` (project references), `vitest`, `prettier`.

## Workspaces
- `apps/cabinet` — личный кабинет, mobile-first (001.62, 001.63).
- `apps/admin` — административная панель (001.62, 001.64).
- `packages/api-client` — клиент API из OpenAPI (001.62).
- `packages/i18n` — словари RU и EN и выбор языка (001.62, 001.65).

## Conventions
- Node 24 LTS (`.nvmrc`); переход на 26 после 2026-10-28.
- `tsconfig.base.json` — строгий режим; каждое рабочее пространство — composite-проект.
