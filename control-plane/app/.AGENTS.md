# Directory: control-plane/app/

## Purpose
Приложение Control Plane (C-01 `api`, C-02 `worker`, C-03 `scheduler`) — один пакет Python,
запускаемый в трёх ролях. Границы модулей — по функциональным компонентам
`docs/architectures/functional-architecture.md`.

## Files

### [__init__.py]
- `__version__` — версия приложения; заполняется при выпуске.

### [cli.py]
- `python -m app.cli migrate [--rollback-all]` — миграции yoyo из `../migrations` под ролью
  `app_migrate` (`MIGRATE_DSN` + `MIGRATE_PASSWORD_FILE` или полный URL), с блокировкой yoyo;
  вызывается точкой входа образа при старте роли `api` (§10.2). `migrate_dsn()` нормализует
  схему в `postgresql+psycopg`. `python -m app.cli admin create` — заглушка до 001.47 (код 69).

## Conventions
- Python 3.14; SQL без ORM (asyncpg); настройки — `pydantic-settings`; проверки — `ruff`, `mypy --strict`.
- Состояние в процессе не хранится (§4.20 постановки): сессии и счётчики — в Redis.
