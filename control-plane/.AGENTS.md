# Directory: control-plane/

## Purpose
Control Plane (Python 3.14, FastAPI): пакет `app/` в трёх ролях процесса, миграции, тесты и
образ Docker. Карта пакета — `app/.AGENTS.md`.

## Files

### [pyproject.toml]
- Метаданные, зависимости `[project]` и `[dev]`, настройки ruff / mypy strict / pytest
  (`python_files = test_*.py` — единственный источник правил обнаружения для `make test-py`).

### [requirements-dev.lock]
- `pip freeze` venv разработки (`make setup`): рантайм + инструменты.

### [requirements.lock]
- Рантайм-зависимости образа — `pip freeze` чистого venv без `[dev]`; версии совпадают с
  `requirements-dev.lock`. Только готовые колёса (`--only-binary=:all:`).

### [Dockerfile]
- Образ C-01…C-03 на `python:3.14-slim`, пользователь `app` (uid 10001), зависимости из
  `requirements.lock`, приложение запускается из `/app` без установки пакета (разработка
  подменяет `/app/app` монтированием). `EXPOSE 8000`; `ENTRYPOINT docker-entrypoint.sh`.

### [docker-entrypoint.sh]
- Стартует от root: копирует секреты из `/run/host-secrets` в `/run/secrets` (владелец `app`,
  0400) и переключается на `app` через `setpriv`. Выбор роли по `APP_ROLE`: `api` →
  `uvicorn app.main:create_app --factory` (`APP_WORKERS`, `APP_RELOAD`; имена `UVICORN_*` не
  используются — их читает сам uvicorn); `worker-critical|worker-background` →
  `python -m app.jobs.worker --queue …`; `scheduler` → `python -m app.jobs.scheduler`. Аргументы
  командной строки выполняются как есть (`docker compose run api python -m app.cli …`).
  Задача 001.03 добавляет миграции (`MIGRATE_DSN`, `MIGRATE_PASSWORD_FILE`) перед `api`.

### [.dockerignore]
- Контекст сборки: только `app/`, `requirements.lock`, `docker-entrypoint.sh`.

### [migrations/]
- SQL-миграции yoyo парами apply/rollback (задача 001.03 и далее).

### [tests/]
- `conftest.py`: фикстуры `pg_dsn`, `redis_url` (стенд по `PG_DSN`/`REDIS_URL`), `app_client`
  (после 001.10).

## Conventions
- Секреты только файлами (`*_FILE` в окружении: `PG_PASSWORD_FILE`, `MIGRATE_PASSWORD_FILE`,
  `APP_ENCRYPTION_KEY_FILE`, `CA_KEY_FILE`, `SMTP_PASSWORD_FILE`), адреса служб — `PG_DSN`
  (роль `app_rw`), `MIGRATE_DSN` (роль `app_migrate`), `REDIS_URL` (§10.3).
- Обновление `requirements*.lock` — вместе, из одного pyproject.
