# Directory: contracts/

## Purpose
Зафиксированные запросы и ответы межкомпонентных интерфейсов — общий источник для обеих сторон
обмена. Файлы правятся людьми: изменение контракта обязано быть видно в diff, поэтому тесты
фикстуры только читают и никогда не перезаписывают.

## Files

### [agent_v1/]
- Node API `/agent/v1` (`docs/architectures/interfaces.md` §5.2): 14 фикстур и `README.md` с
  форматом (`given` — предусловие на стороне Control Plane, `request`, `response`), правилом
  контрольной суммы конфигурации и ограничениями документа, без которых сумма не совпадёт между
  Python и Go. Воспроизводят: `control-plane/tests/contract/test_agent_v1.py` (`make
  test-contract`, стадия «Контракты» §10.2) и `node-agent/internal/contracts` (001.53).
- Эталонные ответы subscription-эндпоинта появятся здесь задачей 001.43.

## Conventions
- Ответ сверяется по разобранному JSON, а не побайтно: порядок ключей и пробелы значения не имеют.
- Набор файлов — часть контракта: он закреплён равенством в тесте, и пропавшая фикстура валит
  прогон, а не сокращает его молча.
- Фикстуры содержат только производные и фиксированные значения; настоящих секретов в них нет.
