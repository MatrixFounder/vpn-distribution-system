## Цель задачи

Подготовить установку ноды одной командой по `docs/architectures/deployment.md` §10.4: Xray-core
v26.3.27 с проверкой контрольной суммы, `node-agent`, юниты systemd, конфигурация агента с двумя
адресами, базовые правила nftables.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `deploy/node/bootstrap.sh` — `bootstrap.sh <enroll_url> <agent_url> <token>`: установка, юниты, `config.yaml`, первый запуск
- `deploy/node/xray.service` — юнит Xray: `api.listen 127.0.0.1:10085`, `Restart=always`
- `deploy/node/node-agent.service` — юнит агента: `After=xray.service`, `Restart=always`, watchdog
- `deploy/node/nftables.conf` — базовые правила §16.6; параметры подставляет агент
- `deploy/node/XRAY_SHA256` — контрольная сумма архива Xray-core v26.3.27 (О-8)

### Интеграция компонентов

Скрипт выдаётся панелью с подставленным токеном (001.25); история оболочки — риск, снимаемый
одноразовостью токена.
