# Задача 001.74: Очередь задач: повторы, экспоненциальная задержка, DLQ с алертом, бюджет ожидания

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа
- UC-04 Учёт трафика и списание с коэффициентом

Требования RTM: R-46.

<!-- contract:goal -->

## Цель задачи

Реализовать логику очереди `jobs` по `docs/architectures/interfaces.md` §5.4: `LISTEN/NOTIFY`,
страховочный опрос, повтор с экспоненциальной задержкой до `max_attempts`, статус `dead` с алертом,
измерение времени ожидания задачи критичного пути (≤ половины бюджета Н-13).

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `control-plane/tests/unit/jobs/test_worker.py` — backoff, `dead`, ожидание критичной задачи ≤ 5 с при пустой очереди

### Изменения в существующих файлах

#### Файл: `control-plane/app/jobs/worker.py`

- `LISTEN jobs_critical` / `jobs_background`; опрос 1 с / 10 с; при ошибке `attempts += 1`, `run_at = now() + backoff(attempts)`; `attempts >= max_attempts` → `dead` + событие для алерта

#### Файл: `control-plane/app/jobs/queue.py`

- `NOTIFY` после коммита через обёртку `transaction()`; `enqueue` возвращает существующую задачу при активном ключе

#### Файл: `control-plane/app/main.py`

- метрики `jobs_wait_seconds{queue}`, `jobs_dead_total`

### Интеграция компонентов

Алерт по `dead` — правило Prometheus (001.68).

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Задача уходит в dead
   - Входные данные: обработчик всегда падает; `max_attempts = 3`
   - Ожидаемый результат: три попытки с растущими интервалами; статус `dead`; событие алерта
2. **TC-E2E-02:** Ожидание критичной задачи
   - Входные данные: постановка в `critical` при работающем исполнителе
   - Ожидаемый результат: выборка не позднее 1 с (`NOTIFY`)

### Модульные тесты

1. **TC-UNIT-01:** Backoff
   - Проверяемая функция: `app/jobs/worker.py::backoff`
   - Входные данные: попытки 1, 2, 3
   - Ожидаемый результат: 1 с, 2 с, 4 с с джиттером

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/unit/jobs tests/e2e/test_jobs.py`
- Полный набор: `make test` — существующие тесты проходят.
