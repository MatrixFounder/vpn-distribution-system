## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Сквозной срез
   - Входные данные: Redeem-код → подключение → трафик с коэффициентом → исчерпание → отзыв
   - Ожидаемый результат: AC-02, AC-04…AC-09 в протоколе
2. **TC-E2E-02:** Пять клиентов
   - Входные данные: Shadowrocket, v2rayNG, Streisand, Hiddify, sing-box
   - Ожидаемый результат: каждый подключается по применимым профилям; заголовки зафиксированы (AC-02, AC-28)
3. **TC-E2E-03:** Нагрузка
   - Входные данные: k6 30 минут
   - Ожидаемый результат: Н-1…Н-4 достигнуты (AC-20)
4. **TC-E2E-04:** Разрыв соединений
   - Входные данные: три стратегии
   - Ожидаемый результат: время разрыва измерено; ОВ-22 закрыт; Н-17 подтверждён или пересмотрен

### Модульные тесты

- Не требуются: задача не содержит логики сверх заглушек или конфигурации.

### Регрессионные тесты

- Команда: `k6 run tests/stand/load/k6-subscription.js`
- Полный набор: `make test` — существующие тесты проходят.
