Тип задачи: `[CONFIGURATION]`.

- UC-07 Отказ и возврат ноды
- UC-08 Ограничение числа адресов и перепродажа доступа

Требования RTM: R-01, R-02, R-07, R-27, R-28, R-41, R-47.

## Цель задачи

Провести приёмку MVP по `docs/TASK.md` §5 на стенде с двумя реальными нодами: заполнить протокол
приёмки по критериям требований приоритета M (AC-01…AC-44, кроме AC-21) и реестр клиентов.
Протокол собирает результаты частей приёмки — 001.73b (сквозной срез §7.2 и пять клиентов),
001.73c (нагрузка, AC-20) и 001.73d (учебное восстановление с нодами, AC-18) — и собственные
проверки задачи: проверки, которым нужна реальная нода или удалённый стенд (AC-11, AC-13 и Н-16,
AC-26, AC-37, AC-40, AC-44); остановка и запуск агента ноды стенда — `offline` и возврат в
`active` по Н-15 (UC-07); уведомление оператору от внешнего сервиса мониторинга 001.68 при
остановленном `api` на публичных доменах стенда (В-43); откат выпуска Control Plane по процедуре
001.71.

Приёмка MVP ждёт только задач требований приоритета M. Задачи приоритета S — 001.32 (R-06),
001.39 (R-29), 001.70 (R-49) и Promo-коды (R-33, в 001.20) — принимаются отдельно, их критерии
проверяются по готовности (решение заказчика 2026-10-25, В-46).

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Проверки на реальной ноде
   - Входные данные: bootstrap ноды на VPS стенда; правила nftables ноды; письмо подтверждения на три почтовые службы; канареечное обновление ноды стенда
   - Ожидаемый результат: AC-11, AC-13 и Н-16, AC-26, AC-37, AC-40, AC-44 — в протоколе
2. **TC-E2E-02:** Откат выпуска
   - Входные данные: выпуск Control Plane, не прошедший критерий процедуры отката 001.71
   - Ожидаемый результат: откат на предыдущий образ выполнен по процедуре; сервис доступен (idea §17.2)
3. **TC-E2E-03:** Внешняя проба на публичных доменах
   - Входные данные: на стенде с публичными доменами (001.73b) `api` остановлен, затем
     запущен
   - Ожидаемый результат: внешний сервис мониторинга (001.68) уведомил оператора не позже двух
     интервалов пробы (проба раз в 1–5 мин — решение заказчика 2026-10-25, В-43); после запуска
     инцидент закрыт
4. **TC-E2E-04:** Отказ и возврат ноды (UC-07)
   - Входные данные: на ноде стенда служба `node-agent` остановлена, затем запущена
   - Ожидаемый результат: нода `offline` не позже Н-15 после последнего heartbeat и исключена из
     ответа эндпоинта; после запуска — `active` и снова в ответе (AC-12, AC-41)
