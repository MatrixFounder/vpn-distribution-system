# Задача 001.85: API панели: карточка ноды с метриками, дашборд, настройки

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-07 Отказ и возврат ноды
- UC-09 Управление тарифами, группами и кодами

Требования RTM: R-34, R-40.

## Цель задачи

Реализовать карточку ноды (статус, метрики за 24 часа, адреса онлайн, соединения, `desired/applied`,
inbound с `error_state`), дашборд §4.15, настройки с валидацией — изменение настройки действует со
следующего запроса, домены подписки только для чтения (В-27) — и пункт «обслуживание»: окно
`silence` в Alertmanager из панели (В-50); решения заказчика 2026-10-25.

  запись `audit.record` с началом, концом и комментарием окна. Alertmanager недоступен — 503

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Домены подписки только для чтения
   - Входные данные: `GET /admin/settings`; `PATCH /admin/settings` с доменами подписки
   - Ожидаемый результат: `GET` отдаёт домены из окружения; `PATCH` — 422, домены не изменились
2. **TC-E2E-02:** Изменение настройки действует сразу
   - Входные данные: `PATCH /admin/settings` режима регистрации `closed`; следующий запрос
     регистрации
   - Ожидаемый результат: регистрация отклонена по новому режиму; строка Audit Log с прежним и
     новым значением
3. **TC-E2E-03:** Ключ вне схемы панели
   - Входные данные: `PATCH /admin/settings` с ключом `email_token_ttl_minutes` (меняет только
     миграция); с ключом вне перечня data-model §4.2.6
   - Ожидаемый результат: 422 в обоих случаях
4. **TC-E2E-04:** Окно обслуживания
   - Входные данные: `POST /admin/settings/maintenance` с началом и концом; `GET`; `DELETE`;
     `POST` при недоступном Alertmanager (фикстура не отвечает)
   - Ожидаемый результат: фикстура Alertmanager получила silence с меткой приоритета
     «Отложенный» и затем его снятие; `GET` показывает окно до снятия; две строки Audit Log; при
     недоступном — 503 `alertmanager_unavailable`

### Модульные тесты

- Не требуются: проверку значений настроек по перечню и тело silence проверяют TC-E2E-02…04 на
  базе и фикстуре Alertmanager; валидатор доменов подписки окружения и его модульный тест — 001.45.

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/e2e/test_admin_nodes.py`
- Полный набор: `make test` — существующие тесты проходят.
