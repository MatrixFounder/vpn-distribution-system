# Задача 001.73d: Учебное восстановление с нодами (AC-18)

Тип задачи: `[CONFIGURATION]`.

## Связь со сценариями
- UC-10 Восстановление Control Plane из резервной копии

Требования RTM: R-43.

<!-- contract:goal -->

## Цель задачи

Провести на стенде 001.73b учебное восстановление с агентами (AC-18): Control Plane
восстанавливается на чистом хосте из копии 001.67 при работающих нодах стенда. Проверяется: сервис
поднят в пределах Н-10 с потерей не больше Н-9; агенты без SSH запросили полный снапшот после
смены `state_generation`; ноды подключились листами прежнего поколения identity в продлённом окне
перекрытия (`docs/TASK.md` UC-10 шаг 5, `docs/idea.md` §5.3; 001.31); отзыв identity после
точки копии действует после восстановления (журнал отзывов 001.67, В-20); агенты повторно
доставили отчёты из буфера; расхождение сверки за период недоступности зафиксировано (001.37d).
Восстановление без нод (часть AC-18) принимает 001.67.
