# Задача 001.60: Node Agent: интерфейс стратегии разрыва и стратегия, выбранная PoC-1а

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа

Требования RTM: R-25.

## Цель задачи

Реализовать интерфейс `Strategy`, выбор по `disconnect_strategy` раздела `agent` ответа состояния,
измерение времени разрыва и только ту стратегию, которую выбрал PoC-1а (001.88, закрывает ОВ-22)
до начала задачи (решение заказчика 2026-10-25, В-11). Выбран `readd` (удаление и повторное
добавление пользователя) — он реализуется здесь; выбран `route_block` — его реализует 001.82 за
интерфейсом этой задачи, а `readd` не реализуется. `restart_inbound` рвёт соединения всех
пользователей inbound, только замеряется в PoC-1а и выбран быть не может (решение заказчика
2026-10-25, В-9).
