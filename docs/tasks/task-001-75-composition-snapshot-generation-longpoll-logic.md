# Задача 001.75: Поток состава: полный снапшот, `state_generation`, long-poll, подтверждение

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-01 Ввод ноды в эксплуатацию
- UC-10 Восстановление Control Plane из резервной копии

Требования RTM: R-04.

<!-- contract:goal -->

## Цель задачи

Реализовать полный снапшот (все строки кроме `removed`), обработку несовпадения `state_generation`
(409 → снапшот), long-poll с ожиданием сообщения Redis до 30 с и возвратом соединения в пул, `ack` с
алертом при расхождении дольше 120 с, контрольную сумму состояния.

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Откат базы
   - Входные данные: `generation` в запросе ≠ базе
   - Ожидаемый результат: 409; следующий запрос `full=1` возвращает снапшот (UC-10)
2. **TC-E2E-02:** Long-poll освобождает соединение
   - Входные данные: 10 удерживаемых запросов при пуле 10
   - Ожидаемый результат: одиннадцатый запрос к базе обслуживается

### Модульные тесты

1. **TC-UNIT-01:** Контрольная сумма
   - Проверяемая функция: `app/domain/composition.py::checksum`
   - Входные данные: одинаковые наборы строк в разном порядке
   - Ожидаемый результат: равные значения

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/e2e/test_agent_api.py -k 'snapshot or generation or longpoll or ack'`
- Полный набор: `make test` — существующие тесты проходят.
