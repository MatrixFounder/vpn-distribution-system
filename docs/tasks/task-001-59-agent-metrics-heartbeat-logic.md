# Задача 001.59: Node Agent: heartbeat, метрики ОС и Xray, экспорт для Control Plane

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-07 Отказ и возврат ноды

Требования RTM: R-05.

<!-- contract:goal -->

## Цель задачи

Реализовать heartbeat раз в 30 с с джиттером, сбор CPU, памяти, диска, сети, числа уникальных
адресов онлайн (Xray) и соединений (ОС), отправку метрик раз в 60 с, версии в heartbeat.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `node-agent/internal/metrics/metrics_test.go` — heartbeat не пропускается при занятом цикле отчётов

### Изменения в существующих файлах

#### Файл: `node-agent/internal/metrics/collect.go`

- `/proc` и `GetStatsOnline`; соединения через `ss -s` или `/proc/net/sockstat`

### Интеграция компонентов

Heartbeat — отдельная горутина; не блокируется отправкой отчётов.
