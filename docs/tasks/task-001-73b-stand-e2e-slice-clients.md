## Цель задачи

Проверить на стенде с двумя реальными нодами в разных странах (`docs/idea.md` §17.1) сквозной срез
§7.2 до приёмки полного перечня (`docs/TASK.md` §1.5, idea §7.2): Redeem-код → подписка →
подключение → учёт с коэффициентом → исчерпание → отзыв. Состав: сквозной срез §7.2; ручная
проверка пяти клиентов §4.2 с фиксацией заголовков и применимых профилей.

Срез подтверждает допущения, от которых зависит остальная приёмка: совместимость пяти клиентов,
точность учёта при перезапуске Xray (Н-19), идемпотентность отчётов (Н-20), задержку отзыва
доступа (Н-14 = Н-13) и перерасход (Н-17, Н-17а). Н-17 и Н-17а меряются на стратегии разрыва,
выбранной ранней задачей 001.88 (PoC-1а, ОВ-22; решение заказчика 2026-10-25, В-11).

Control Plane стенда поднят на VPS заказчика промышленным профилем Compose 001.66 с публичным
server 001.66b; ноды — bootstrap 001.61 на отдельных VPS (ноды на VM разработки не ставятся,
`CLAUDE.md`).
