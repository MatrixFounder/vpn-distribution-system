Тип задачи: `[LOGIC IMPLEMENTATION]`.

- UC-09 Управление тарифами, группами и кодами

Требования RTM: R-18, R-30.

## Цель задачи

Реализовать `PlanService` и `GroupService` с правилами §4.8, §4.10 источника и датированными
коэффициентами §4.2.2 архитектуры.

## Описание изменений

### Новые файлы

- `control-plane/tests/e2e/test_catalog.py` — реальные утверждения; A1…A5 из UC-09

### Изменения в существующих файлах

#### Файл: `control-plane/app/domain/plans.py`

- `create`/`update`: валидация полей, `Price` справочное, связь с группами доступа и профилями
- `archive`: отклонение удаления при активных подписках (UC-09 A4)

#### Файл: `control-plane/app/domain/groups.py`

- `set_billing_group(node_id, group_id, override_milli | None)`: закрытие текущего интервала `node_billing_assignments`, открытие нового, обновление денормализации `nodes.*`, принудительное закрытие периода агрегации через `AccountingService.close_hour(node_id)` (001.34)
- `set_group_multiplier(group_id, milli)`: новый интервал `billing_group_multipliers`
- валидация коэффициента 0…10000 кратно 100 (UC-09 A2)

### Интеграция компонентов

Изменения коэффициента пишутся в Audit Log через `audit.record(...)` (001.48; до него — заглушка).

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Вторая тарифицируемая группа отклонена
   - Входные данные: назначение ноде второй группы
   - Ожидаемый результат: 409; `nodes.billing_group_id` без изменений (UC-09 A1)
2. **TC-E2E-02:** История коэффициента
   - Входные данные: два изменения множителя группы подряд
   - Ожидаемый результат: два интервала без пересечения; `EXCLUDE` не нарушен

### Модульные тесты

1. **TC-UNIT-01:** Валидация коэффициента
   - Проверяемая функция: `app/domain/groups.py::validate_multiplier`
   - Входные данные: `10001`, `150`, `2000`
   - Ожидаемый результат: ошибка, ошибка, успех

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/e2e/test_catalog.py -k 'plan or group' tests/unit/domain/test_groups.py`
- Полный набор: `make test` — существующие тесты проходят.
