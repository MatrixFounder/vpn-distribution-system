# Задача 001.58: Node Agent: блокировка адресов через RoutingService с переустановкой

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-08 Ограничение числа адресов и перепродажа доступа

Требования RTM: R-27.

<!-- contract:goal -->

## Цель задачи

Реализовать применение `blocked_ips[]` правилами `RoutingService` с сохранением в Store и
переустановкой после перезапуска, базовые правила nftables (порты 25/587, частные сети, метаданные,
частота новых соединений) и лимит соединений с одного адреса (Н-29), сбор счётчиков conntrack по
адресам.
