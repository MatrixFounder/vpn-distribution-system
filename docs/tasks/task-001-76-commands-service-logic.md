# Задача 001.76: Служба команд: выдача в ответе состояния, идемпотентность, TTL, статусы

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-11 Обновление парка нод
- UC-12 Компрометация ноды

Требования RTM: R-04.

<!-- contract:goal -->

## Цель задачи

Реализовать `CommandService`: выдача команд в ответе long-poll по матрице §4.6, `expires_at`, повтор
по `command_id` без повторного исполнения, статусы `issued → delivered → applied|failed|expired`,
приём результата.

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Повтор не исполняется
   - Входные данные: команда доставлена дважды
   - Ожидаемый результат: `delivered` один раз; результат один
2. **TC-E2E-02:** Просроченная команда
   - Входные данные: команда с `expires_at` в прошлом
   - Ожидаемый результат: не выдаётся; выборка ставит `expired`; путь `expired` от агента (команда истекла у агента до исполнения, UC-11 A3) — фикстура `command-result`
3. **TC-E2E-03:** Публикация после коммита
   - Входные данные: подписчик Redis на канал `node:{id}`; выдача команды ноде
   - Ожидаемый результат: одно сообщение в канале; в момент его получения строка команды видна отдельному подключению к базе (публикация после коммита)

## Примечания

Ограничения и допущения — `docs/idea.md` §9; архитектура — `docs/ARCHITECTURE.md`.


Найдено при 001.28 (заглушки), решить здесь:

- `CommandService.result(node_id, command_id, status, error)` принимает и ноду (отклонение от
  сигнатуры, объявленной в 001.28): без сверки `commands.node_id` любая нода закрывала бы чужую
  команду по угаданному идентификатору;
- от ноды принимаются только `applied | failed | expired`; `issued` и `delivered` ставит Control
  Plane, и схема их отвергает;
- вентиль §4.6 закрывает канал команд в `disabled` и `suspended`; приём результата в этих
  статусах заглушка не ограничивает — решить, отклонять ли отчёт по команде, выданной до
  перевода;
- текст ошибки исполнения приходит от недоверенной ноды (§11.3) и попадёт в журнал и в панель:
  вычистить управляющие символы на границе, длина уже ограничена `ERROR_MAX_CHARS`.
