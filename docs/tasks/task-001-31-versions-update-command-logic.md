# Задача 001.31: Закреплённые версии, команда `update_agent`, ротация identity с перекрытием

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-11 Обновление парка нод
- UC-12 Компрометация ноды

Требования RTM: R-07, R-44.

<!-- contract:goal -->

## Цель задачи

Реализовать выдачу команд `update_agent`, `restart_xray`, `rotate_credentials`,
`collect_diagnostics`, учёт версий в `settings` и ротацию identity ноды с окном перекрытия (Н-28) и
продлением после отката (§5.3).

- `POST /admin/nodes/{id}/commands` с типом и полезной нагрузкой; чтение результата
