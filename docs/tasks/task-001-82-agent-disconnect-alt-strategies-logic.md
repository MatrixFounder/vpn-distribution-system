# Задача 001.82: Node Agent: стратегия разрыва `route_block` (только при выборе PoC-1а)

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа

Требования RTM: R-25.

<!-- contract:goal -->

## Цель задачи

Реализовать стратегию `route_block` (правило `RoutingService` по адресам пользователя онлайн на
`blackhole`) за интерфейсом `Strategy` (001.60) с измерением времени разрыва. Задача выполняется,
только если PoC-1а (001.88) выбрал `route_block`; выбран `readd` — задача снимается из плана
(решение заказчика 2026-10-25, В-11). `restart_inbound` не реализуется: он рвёт соединения всех
пользователей inbound, только замеряется в PoC-1а и выбран быть не может (решение заказчика
2026-10-25, В-9).

### Изменения в существующих файлах

#### Файл: `node-agent/internal/disconnect/strategies.go`

- правила `route_block` — с тегом `dc-{xray_email}`; хранятся в Store вместе с правилами 001.58,
  переустанавливаются после каждого старта Xray (001.80) и снимаются, когда для пользователя
  приходит строка `active`

### Интеграция компонентов

Выбор — `disconnect_strategy` раздела `agent` ответа состояния (контракт — 001.26, значение —
001.40); замер стратегий и выбор — PoC-1а 001.88 до начала задачи; эта задача от него зависит.
