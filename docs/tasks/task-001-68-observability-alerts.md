## Цель задачи

Экспортировать метрики §9.3 архитектуры из C-01…C-03, настроить Prometheus и Alertmanager с
правилами §17.4 источника, группировкой, подавлением, окном обслуживания и инструкцией на каждый

## Описание изменений

### Новые файлы

- `deploy/prometheus/prometheus.yml` — цели `api`, `worker-*`, `scheduler`
- `deploy/prometheus/alerts.yml` — семь правил §17.4 с приоритетами; исключение ручных статусов
- `deploy/prometheus/alertmanager.yml` — маршрут webhook оператора; группировка по ноде и типу; `inhibit` для окна обслуживания
- `docs/runbooks/README.md` — инструкции разбора по каждому алерту (R-50, руководство оператора)

### Изменения в существующих файлах

#### Файл: `control-plane/app/main.py`

- `/metrics`: латентность и коды по маршрутам, глубина и возраст очередей, ноды по статусам, возраст последнего отчёта, расхождения сверок, доставки

### Интеграция компонентов

Метрики нод — из `node_metrics` через C-01.
