`docs/architectures/data-model.md` §4.2.2 и правило целочисленного списания §4.9.

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Поздний отчёт получает коэффициент своего периода
   - Входные данные: смена коэффициента 2.0 → 3.0 в 12:00; отчёт за 11:30 принят в 12:30
   - Ожидаемый результат: строка получает 2.0 (UC-04 A7)

### Модульные тесты

1. **TC-UNIT-01:** Приоритет переопределения
   - Проверяемая функция: `app/domain/multiplier.py::resolve`
   - Входные данные: нода с override 3.0 в группе 2.0
   - Ожидаемый результат: 3.0
2. **TC-UNIT-02:** Отсутствие назначения
   - Проверяемая функция: `resolve`
   - Входные данные: момент до ввода ноды
   - Ожидаемый результат: 1.0 с `source = default`
3. **TC-UNIT-03:** Целочисленное списание
   - Проверяемая функция: `billable`
   - Входные данные: `raw = 1_000_000_001`, `milli = 1500`
   - Ожидаемый результат: `1_500_000_001`; `floor`, без float

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/unit/domain/test_multiplier.py`
- Полный набор: `make test` — существующие тесты проходят.
