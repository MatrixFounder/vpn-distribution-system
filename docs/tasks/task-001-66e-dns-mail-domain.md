## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Записи доменов
   - Входные данные: `dig A` и `dig AAAA` доменов кабинета, панели и двух доменов подписки
   - Ожидаемый результат: адреса хоста Control Plane
2. **TC-E2E-02:** Записи домена писем
   - Входные данные: `dig TXT` домена писем (SPF), селектора DKIM провайдера и `_dmarc`; проверка DMARC
   - Ожидаемый результат: значения выбранного провайдера; проверка DMARC проходит

### Модульные тесты

- Не требуются: задача не содержит логики сверх заглушек или конфигурации.

### Регрессионные тесты

- Команда: `dig` из TC-E2E-01 и TC-E2E-02 по шаблону `deploy/README.md`
- Полный набор: `make check` — существующие тесты проходят.

## Примечания

Конфигурационная задача. Записи домена писем ждут выбора провайдера (ОВ-13; выбор — до 001.78).
Проверка требует реальных доменов, нод не требует (PLAN-22).
