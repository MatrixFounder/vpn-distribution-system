# Задача 001.81: Node Agent: исполнение команд и `update_agent` с откатом

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-11 Обновление парка нод
- UC-12 Компрометация ноды

Требования RTM: R-04, R-07.

<!-- contract:goal -->

## Цель задачи

Реализовать исполнение команд: дедупликация по `command_id` в Store, `expires_at` → результат
`expired`, четыре типа команд, `update_agent` с загрузкой, проверкой контрольной суммы, заменой
бинарного файла, перезапуском через systemd и откатом при неуспехе.

<!-- contract:changes -->
