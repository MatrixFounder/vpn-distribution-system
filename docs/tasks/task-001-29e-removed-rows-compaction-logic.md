## Цель задачи

Реализовать уплотнение строк `removed` потока состава (`data-model.md` §4.2.3): строка `removed`
удаляется после того, как нода подтвердила применённый курсор `applied_users_seq`, не меньший её
`updated_seq`. Запись `applied_users_seq` по подтверждению — 001.75; строки `removed` пишут
001.29 и 001.29b.
