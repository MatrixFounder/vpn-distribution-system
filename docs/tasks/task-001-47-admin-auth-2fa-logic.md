# Задача 001.47: Аутентификация администраторов: TOTP, резервные коды, сессии

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-09 Управление тарифами, группами и кодами

Требования RTM: R-36.

<!-- contract:goal -->

## Цель задачи

Реализовать обязательный второй фактор, резервные коды, сессии с TTL бездействия 12 часов (Н-27),
инвалидацию при блокировке ≤ 60 с и процедуру восстановления с участием второго держателя по
`docs/architectures/security.md` §7.1.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `control-plane/tests/e2e/test_admin_auth.py` — реальные утверждения; блокировка → сессии недействительны за 60 с (AC-16)

### Изменения в существующих файлах

#### Файл: `control-plane/app/security/totp.py`

- pyotp; секрет в `totp_secret_enc`; 10 резервных кодов, хеши в `admin_recovery_codes`; использование — в Audit Log

#### Файл: `control-plane/app/api/admin/auth.py`

- двухшаговый вход; сессия `kind = admin` с TTL 12 ч бездействия; сброс второго фактора — только через `recovery` с подтверждением второго администратора (запись `audit_log`, уведомление остальных)

#### Файл: `control-plane/app/cli.py`

- `admin create --email` (первый Super Admin) с обязательным включением второго фактора при первом входе

### Интеграция компонентов

Сессии — `SessionStore` (001.14).

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Вход с TOTP
   - Входные данные: пароль + код
   - Ожидаемый результат: cookie сессии `admin`
2. **TC-E2E-02:** Блокировка инвалидирует
   - Входные данные: блокировка учётной записи с активной сессией
   - Ожидаемый результат: запрос через 1 с → 401 (AC-16)
3. **TC-E2E-03:** Резервный код однократен
   - Входные данные: один код дважды
   - Ожидаемый результат: второй — 401; записи `audit_log`

### Модульные тесты

1. **TC-UNIT-01:** Проверка TOTP
   - Проверяемая функция: `app/security/totp.py::Totp.verify`
   - Входные данные: код текущего окна; код прошлого часа
   - Ожидаемый результат: истина; ложь

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/e2e/test_admin_auth.py tests/unit/security/test_totp.py`
- Полный набор: `make test` — существующие тесты проходят.
