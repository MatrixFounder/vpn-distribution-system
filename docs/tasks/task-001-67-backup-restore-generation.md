## Примечания

Конфигурационная задача; хранилище — ОВ-A1.

Найдено при 001.25 (enrollment и identity), решить здесь:

- отзыв identity живёт столько, сколько живёт база: восстановление из копии, снятой до отзыва,
  молча вернёт отозванные identity и неиспользованные токены, аннулированные после копии (токены
  ограничены сроком Н-24, identity — нет, до 90 дней). Прокси их не отвергнет (`ssl_crl` — 001.66).
  Процедура восстановления обязана вернуть отзывы, сделанные после точки копии (журнал аудита
  001.48 или внешний список отзывов), либо сменить CA и перевыпустить парк; до этого — не
  открывать агентский порт.
- локальный архив WAL стенда (`archive_command` в `deploy/compose/docker-compose.yml`) ограничен
  по возрасту (удаление сегментов старше 3 суток), а не по объёму: прогоны набора при посадках
  001.25 записали 15,9 ГБ, диск VM заполнился, PostgreSQL упал при восстановлении, Redis
  отказал в записи (2026-09-25). На стенде `.env` VM задаёт `PG_ARCHIVE_COMMAND` с хранением
  6 ч (решение заказчика). Архив pgBackRest — с хранением по числу полных копий и
  предупреждением о месте на диске (метрика, алерт), а не только по времени.
