- UC-10 Восстановление Control Plane из резервной копии

Требования RTM: R-43.

## Цель задачи

Настроить pgbackrest с шифрованием и удалённым хранилищем (ОВ-A1), `archive_timeout = 900` (Н-9),
метку поколения в `/var/lib/control-plane/generation`, скрипт восстановления и учебный прогон (Н-10,
Н-11).

- `deploy/scripts/restore-drill.md` — инструкция учебного восстановления и журнал прогонов

### Изменения в существующих файлах
