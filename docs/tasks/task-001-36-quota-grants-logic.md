# Задача 001.36: Гранты квоты: выдача, замена, учёт расхода, ограничение Н-17

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа

Требования RTM: R-26.

<!-- contract:goal -->

## Цель задачи

Реализовать правило гранта из `docs/architectures/interfaces.md` §5.2: `min(Н-17, остаток) / N`
для тарифов с лимитом и грант без ограничения для Unlimited (решение заказчика 2026-10-25, В-6),
замена прежнего гранта, подтверждение расхода отчётами, включение `quota_grant_bytes` с номером
выдачи `quota_issued_seq` в поток состава.

## Примечания

Размер гранта — правило interfaces §5.2 без отдельной настройки; шаг запроса — 50 % гранта
(idea §4.11).

Найдено при 001.33 (заглушки), решить здесь:

- `consumed_bytes` запроса гранта — самоотчёт, назначение (сигнал расхождения с подтверждённым
  расходом) решить здесь;
- схема: монотонность `issued_seq` на пару «пользователь × нода» (`CHECK`/уникальность) —
  сегодня правило живёт только в README контракта;
- `STUB_QUOTA_GRANT_BYTES` живёт в домене (`domain/composition.py`), служба грантов импортирует
  его оттуда — домен от учёта не зависит (правило слоёв в `accounting/.AGENTS.md`): заменяя
  заглушку, дать потоку состава настоящий грант через `QuotaService` из графа зависимостей
  (`agent_api/deps.py`), а не через импорт константы и не импортом учёта из домена;
- `QuotaService` приходит в `AccountingService` из `deps.get_accounting_service`: подменять и
  расширять фабрику, а не конструктор службы приёма;
- типизация без ребра домен → учёт: страж правила слоёв разбирает импорты и **не считает**
  ветку `if TYPE_CHECKING:` — `CompositionService` может аннотировать `QuotaService` так; либо
  объявить в домене `Protocol` (например, `QuotaSource.grant(...)`), которому `QuotaService`
  удовлетворяет структурно. `Any` на денежном пути не допускается;
- `POST /agent/v1/quota/request` после этой задачи пишет в `quota_grants`: частота по
  сертификату на прокси — 5 запросов в секунду с очередью 20 (`agent_rate`) и 15 в секунду на
  весь парк (`agent_fleet_rate`, очередь 200), предел по identity в приложении — 001.72;
  согласовать порог выдачи (не чаще, чем нода может законно израсходовать грант).
