# Задача 001.36: Гранты квоты: выдача, замена, учёт расхода, ограничение Н-17

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа

Требования RTM: R-26.

<!-- contract:goal -->

## Цель задачи

Реализовать правило гранта из `docs/architectures/interfaces.md` §5.2: `min(Н-17, остаток) / N`,
замена прежнего гранта, подтверждение расхода отчётами, включение `quota_grant_bytes` в поток
состава.

<!-- contract:changes -->

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Сумма грантов ограничена
   - Входные данные: пользователь на 3 нодах; запросы грантов
   - Ожидаемый результат: сумма непогашенных ≤ Н-17 в единицах списания (AC-09)
2. **TC-E2E-02:** Новый грант заменяет
   - Входные данные: повторный запрос при остатке
   - Ожидаемый результат: прежний `superseded_at`; выдан один новый

### Модульные тесты

1. **TC-UNIT-01:** Размер гранта
   - Проверяемая функция: `app/accounting/quota.py::grant_size`
   - Входные данные: остаток 1 ГБ, N = 4, Н-17 = 3 ГБ
   - Ожидаемый результат: 256 МБ
