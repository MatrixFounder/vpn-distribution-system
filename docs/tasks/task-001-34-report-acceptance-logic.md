## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Повтор отчёта
   - Входные данные: тот же ключ дважды
   - Ожидаемый результат: баланс без изменений; `duplicate = true` (AC-06)
2. **TC-E2E-02:** Аномальный прирост
   - Входные данные: дельта больше полосы ноды за интервал
   - Ожидаемый результат: `held_anomaly`; баланс без изменений; алерт
3. **TC-E2E-03:** Отклонение времени
   - Входные данные: `period_end` на 10 с в будущем
   - Ожидаемый результат: `rejected_time`; алерт

1. **TC-UNIT-01:** Порог аномалии

   - Входные данные: 100 Мбит/с, 60 с
   - Ожидаемый результат: 750 МБ
