## Цель задачи

Собрать обязательные документы §17.13 источника: OpenAPI в CI как артефакт с версией, руководство
оператора (установка, восстановление, канареечное обновление, откат выпуска, инструкции по
алертам), инструкции пользователя по клиентам §4.2, журнал архитектурных решений.

## Описание изменений

### Новые файлы

- `docs/operations/README.md` — руководство оператора; в нём:
  - процедура отката выпуска Control Plane с критерием решения об откате (idea §17.2); проверка
    на стенде — 001.73
  - обновление парка: минимальная поддерживаемая версия агента поднимается только после
    обновления всего парка — нода с версией ниже минимальной получает 426 на всех операциях,
    включая запрос состояния, и `update_agent` не получает
  - вывод ноды из эксплуатации (§4.6 «Удаление», UC-12 A2; решение заказчика 2026-10-25,
    В-21): на ноде по SSH — подкоманда `node-agent decommission` (слив буфера, финальное чтение
    счётчиков, затирание identity и секретов; 001.81), затем вывод в панели (001.87), затем
    уничтожение VPS; канал команд §5.2 для вывода не используется; нода, уничтоженная без вывода,
    — период недоучёта записью с признаком (§5.9)
  - обращение провайдера (§16.7; решение заказчика 2026-10-25, В-45): регистрация в панели
    (001.69), выборка пользователей с трафиком на ноде в интервале жалобы; провайдеру — только
    факт приостановки и принятые меры, без идентификаторов и объёмов пользователей
  - восстановление (001.67): ключ шифрования копий — из менеджера паролей оператора или у второго
    держателя §17.12 (В-44); отзывы после точки копии возвращает журнал отзывов до открытия
    агентского порта (В-20)
- `docs/user-guide/{ru,en}/README.md` — инструкции по установке клиентов, импорту подписки и диагностике (idea §17.13)
- `docs/adr/README.md` — ADR: решение §0.3 источника — вариант Build, PoC-1а — ранняя задача
  001.88 (решение заказчика 2026-10-25, В-11), закрытые вопросы §15.2, стек, очередь в
  PostgreSQL, модель удаления
- `docs/clients-registry.md` — реестр клиентов §17.10, шаблон: клиент, платформа, версия, формат, заголовки, дата проверки; строки заполняет 001.73

### Изменения в существующих файлах
