# Задача 001.57: Node Agent: локальный грант квоты и автономное отключение

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-05 Исчерпание лимита и отзыв доступа

Требования RTM: R-26.

<!-- contract:goal -->

## Цель задачи

Реализовать учёт `quota_grant_bytes` по пользователю: уменьшение по дельтам, запрос следующего
гранта при 50 %, локальный перевод в `suspended_quota` (`RemoveUser` + стратегия разрыва) при
исчерпании без связи.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `node-agent/internal/quota/quota_test.go` — без связи: пользователь отключён при исчерпании гранта; при связи — новый грант заменяет остаток

### Изменения в существующих файлах

#### Файл: `node-agent/internal/quota/quota.go`

- `type Tracker`: остаток гранта в Store; `OnDelta(user, bytes)`; `RequestIfNeeded`; `OnExhausted` → 001.60

### Интеграция компонентов

Грант приходит в строке потока состава (001.55) и по ответу `quota/request`.
