# Задача 001.56: Node Agent: счётчики, эпохи, буфер SQLite, отчёты, синхронизация времени

Тип задачи: `[LOGIC IMPLEMENTATION]`.

## Связь со сценариями
- UC-04 Учёт трафика и списание с коэффициентом

Требования RTM: R-19, R-20.

<!-- contract:goal -->

## Цель задачи

Реализовать чтение счётчиков без сброса, вычисление дельт внутри `counter_epoch`, персистентный
буфер отчётов ≥ 24 часов, отправку по порядку `report_seq`, ответ `last_accepted_seq`, финальное
чтение перед перезапуском, контроль отклонения времени.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `node-agent/internal/accounting/collector_test.go` — перезапуск Xray во время передачи: ни потери, ни повтора (Н-19)

### Изменения в существующих файлах

#### Файл: `node-agent/internal/accounting/collector.go`

- `QueryStats` каждые 60 с; дельта по пользователю; убывание → журнал + пропуск строки + метрика; сбор адресов онлайн и счётчиков интерфейса ОС

#### Файл: `node-agent/internal/accounting/buffer.go`

- SQLite: таблица `reports(seq, epoch, body, created_at)`; ёмкость 24 ч; переполнение → удаление старейших + метрика

#### Файл: `node-agent/internal/accounting/sender.go`

- отправка по возрастанию `seq`; `duplicate` → удаление из буфера; недоступность → накопление

#### Файл: `node-agent/internal/accounting/clock.go`

- проверка смещения по ответу Control Plane (`Date`) и NTP-статусу; смещение > 5 с → предупреждение и метрика

### Интеграция компонентов

Финальное чтение вызывается из 001.55 перед перезапуском.

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Перезапуск не искажает учёт
   - Входные данные: передача 100 МБ с перезапуском Xray посередине
   - Ожидаемый результат: сумма дельт по двум эпохам = 100 МБ (AC-05)
2. **TC-E2E-02:** Буфер переживает недоступность
   - Входные данные: Control Plane недоступен 10 минут
   - Ожидаемый результат: все отчёты доставлены после восстановления в порядке `seq`; `duplicate` обработан

1. **TC-UNIT-01:** Дельта внутри эпохи

   - Входные данные: счётчик 40 ГБ → 0 после рестарта
   - Ожидаемый результат: новая эпоха; дельта 0; без отрицательных значений
