Тип задачи: `[LOGIC IMPLEMENTATION]`.

- UC-16 Работа в личном кабинете

## Цель задачи

Реализовать чтение состояния подписки, статистику из `traffic_hourly`, перевыпуск токена с ротацией
credentials и данные мастера первого подключения.

## Описание изменений

### Новые файлы

- `control-plane/tests/e2e/test_me.py` — реальные утверждения по данным фикстур трафика

### Изменения в существующих файлах

#### Файл: `control-plane/app/domain/profile.py`

- `update`: язык из `{ru, en}`, часовой пояс IANA, согласие на канал объявлений

#### Файл: `control-plane/app/accounting/stats.py`

- агрегация `traffic_hourly` за период по ноде и стране; остаток = лимит − `used_billable_bytes`; `active_ips` из `user_online_ips`

#### Файл: `control-plane/app/api/me.py`

- `reissue`: вызов `SubscriptionTokenService.reissue(user_id)` (001.42) → ротация credentials через `CompositionService` (001.29)
- `onboarding`: платформа по `User-Agent`, ссылки на клиенты §4.2 из `settings`, ссылка импорта и QR

### Интеграция компонентов

Статистика читает `traffic_hourly`; перевыпуск пишет `subscription_tokens` и ставит задачу
`critical` на публикацию новых credentials.

## Тестовые случаи

### Сквозные тесты

1. **TC-E2E-01:** Статистика отражает фикстуры
   - Входные данные: две строки `traffic_hourly` на нодах с коэффициентами 1.0 и 2.0
   - Ожидаемый результат: `raw` и `billable` по нодам совпадают; остаток вычислен
2. **TC-E2E-02:** Перевыпуск ротирует credentials
   - Входные данные: `POST /me/subscription/reissue?confirm=true`
   - Ожидаемый результат: прежний токен → 404; `node_user_credentials.version` увеличен для всех нод пользователя
   - Примечание: AC-35

### Модульные тесты

1. **TC-UNIT-01:** Агрегация по стране
   - Проверяемая функция: `app/accounting/stats.py::user_traffic`
   - Входные данные: строки по двум нодам одной страны
   - Ожидаемый результат: суммы по стране равны сумме по нодам

### Регрессионные тесты

- Команда: `cd control-plane && pytest tests/e2e/test_me.py tests/unit/accounting/test_stats.py`
- Полный набор: `make test` — существующие тесты проходят.
