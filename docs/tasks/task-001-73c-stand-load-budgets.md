## Цель задачи

Провести на стенде 001.73b нагрузочный прогон 30 минут при профиле О-3 (AC-20; `docs/idea.md` §14
«Нагрузка»): Н-1…Н-3 — k6, Н-4 — синтетические агенты; p95 Н-4 — по времени апстрима (`urt`)

принимается на значениях О-3: нормы §13 проверяются на приёмке на О-3 (idea §5.7).

Перемерить под парком §5.7 бюджеты прокси и приёма (константы гейта Н-4, транзакция приёма против
резерва 50 мс, `lock_timeout`, `--limit-concurrency`) и потолки контейнеров по примечаниям. Это
техническая калибровка выведенных констант (контракт `contracts/agent_v1/README.md` — «измерение
на целевой VPS»): её числа заменяют выведенные значения и критериями приёмки MVP не являются
(idea §5.7; OPS-23).

- бюджет Н-4 (по решению заказчика — по времени апстрима `urt`, заливка вне норматива): гейт

  p95 88, 14,7 мкс), на замере пар одновременных частей (p95 второй из пары 69 мс ≤ 2 × 50 —

  `enqueue`) вместе с пулом (`max_size=10` на процесс против
