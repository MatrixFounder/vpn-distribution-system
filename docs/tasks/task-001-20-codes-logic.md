## Цель задачи

Реализовать `CodeService`: код с контрольной суммой, шифрование для экспорта, ограничения
использования, активация через `SubscriptionService`.

<!-- contract:changes -->

## Описание изменений

### Новые файлы

- `control-plane/tests/e2e/test_catalog.py` — активация: однократность, повтор → 409, просроченный → 410 (UC-02 A3, A4)

### Изменения в существующих файлах

#### Файл: `control-plane/app/domain/codes.py`

- `generate() -> str`: формат `VPN-XXXX-XXXX`, ≥ 40 бит энтропии, последние два символа — контрольная сумма
- `create_batch`: `codes` со `code_hash` и `code_enc` (FieldCipher), `batch_id`
- `redeem`: проверка суммы до базы, срока, `max_uses`, `max_uses_per_user`, `plan_id`; вызов `SubscriptionService.activate|renew|bonus`; запись `code_redemptions`; лимит частоты `rl:redeem:acct:{id}`
- `export`: расшифровка `code_enc` только для роли с разрешением `codes.export`; факт экспорта — в Audit Log

### Интеграция компонентов

Активация — транзакция с `SubscriptionService` (001.22); бонус трафика →
`balance_entries(source=bonus)`.
